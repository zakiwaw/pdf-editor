# PDF Editor

PDFs online bearbeiten, ohne Installation und ohne Muse.

- PDF-Dateien hochladen
- Seiten ansehen, löschen, drehen und umsortieren
- Mehrere PDFs zusammenstellen
- Neues PDF herunterladen

Die schwere PDF-Arbeit läuft mit C++ (QPDF, per WebAssembly im Browser).
Alle Dateien bleiben im Browser, sie werden nirgendwo hochgeladen.

Online benutzen: https://zakiwaw.github.io/pdf-editor/
